# 阶段计划

按"每一阶段都能独立收口"来切。低阶段的成果不能当高阶段用，做不完就在这一层停下。

| 阶段 | 目标 | 完成标准 |
|---|---|---|
| S0 | 工具链闭环 | 二态仿真、四态 X/Z 判败、综合、干净重建全过 |
| V1 | 独立计算核 | 逐拍数据流能对上、随机与极值逐元素一致、有综合报告 |
| V2 | 单时钟 SoC | Ibex 裸机提交任务、读回结果，与 Python 参考逐项一致 |
| V3 | 双时钟域 | 两个异步 FIFO，任意频率比下无丢失/重复/错序，复位策略一致 |
| V4 | 实物与实测 | 上板跑真实层、有时序约束和资源/吞吐数据 |

## S0：工具链闭环

- 写一个带同步复位和使能的 8 位计数器，只用来验证工具链，不做别的。
- 自检 tb 要能真的 FAIL：故意改错期望值必须红，再改回来。
- 三条路都要通：Verilator 二态仿真、Icarus 四态（强制 X/Z 必须判败）、Yosys 综合。
- 判据：任何一步失败脚本要返回非零，不能只看"跑完了"。

## V1：独立计算核

- 数值：`C[i][j] = Σ A[i][k]·B[k][j]`，操作数有符号 INT8，累加 32 位，不定义溢出/饱和。
- 结构：`PE(r,c)` 驻留 `B[r][c]`，激活向东、部分和向南，每 PE 一拍寄存。
- 逐拍：装载 4 拍 → 注入 16 拍 → 捕获 16 拍；接受后 24 拍出最后结果、25 拍可握手、最小任务间隔 26 拍。
- 验证：Python 纯整数参考模型 + 固定种子随机向量（含手算样例、极值、单位阵）；逐拍 scoreboard 独立算期望；故障注入必须判败。
- 综合：PE 和阵列分别综合，各自出报告，资源数字当基线记下来。
- 交付：规格文档、golden、向量、RTL、tb、检查器、综合报告。

## V2：单时钟 SoC

拆三段做，不跳步。

1. **Ibex 裸机基线**：固定 Ibex 版本和 simple-system 内存图，裸机程序跑自检并输出唯一 PASS 标记；再补"强制失败"和"不发 halt"两条真实负路径。
2. **NPU MMIO**：地址窗口、寄存器、原子提交、16 beat 结果与 ACK、非法访问报错、复位语义；软件侧读结果前后加 fence。
3. **真实网络层**：从 `hello_world_int8.tflite` 取 `dense_1` 这层（16×16、融合 ReLU、全整数 PTQ），软件分块提交、全 K 合并、bias 只加一次、零点修正后重新量化，与 Python 参考逐项比对；再做一条 Ibex 纯软件的基线算周期。

## V3：双时钟域

- 结构：CPU 域写完整快照 → 异步命令 FIFO → NPU 域；结果反向走异步结果 FIFO。
- FIFO：指针跨域用格雷码 + 两级同步器，存储体按协议保持稳定；深度从 2/4 起步，用仿真和资源数据定。
- 满空与背压：结果 FIFO 满时 NPU 停推；软件见非空就排空，不等 16 项全入队，否则小深度会死锁。
- 复位：异步断言、各域同步释放；在途任务统一"两域清空、软件重提"，避免读出半个任务。
- 验证：两组以上频率比、非对齐相位、满/空边界、复位场景；对 FIFO 做形式验证（无已接受数据丢失/重复/乱序、无读空、无写满越界）。
- 不做：把异步 FIFO 当万能同步器、给跨域路径粗暴 `false_path` 就宣称 CDC 签核。

## V4：实物与实测

- 两路真实独立板上时钟；上板跑真实网络层，结果可观测。
- 约束：时钟定义、跨域时钟组、输入输出延迟；报告最差路径和余量。
- 指标：纯软件基线周期、阵列计算周期、端到端周期、单任务延迟、连续任务吞吐、资源占用、最高可用频率。功耗只在有可信活动因子时报告，并区分估计与实测。
- 至少两组频率比、两组 FIFO 深度，一次只改一个变量；负结果也留着并解释。

## 砍功能的顺序

完整 MLP/CNN 推理 → im2col 卷积映射 → 8x8 阵列 → DMA/AXI → 复杂低功耗 → 整 SoC GDS。

**不砍**：真实网络层、纯软件基线、golden 模型、自检 tb、可复现脚本、对真实时序/资源数据的分析。
