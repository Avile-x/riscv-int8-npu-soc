# 阶段计划

本文件记录各阶段的范围、设计草案与验收条件，不代表已实现功能。当前所有阶段均未完成；完成后应补充复现命令、测试记录和报告。

## S0：工具链验证

用一个带同步复位和使能的 8 位计数器验证仿真、综合与回归流程。

验收条件：

- Verilator 仿真与自检通过。
- Icarus 四态仿真能检测注入的 X/Z，并使测试失败。
- 修改期望值后，自检能报告失败。
- Yosys 综合通过。
- 从干净的构建目录运行统一入口，任一步骤失败均返回非零退出码。

交付：计数器 RTL、自检测试平台、构建与回归脚本、运行记录。

## V1：独立计算核

实现 4×4 weight-stationary 脉动阵列，单次计算：

```text
C[i][j] = Σ(k=0..3) A[i][k] × B[k][j]
```

设计约束：

- A、B 为有符号 INT8，累加与结果为 32 位；首版不引入饱和运算。
- `PE(r,c)` 驻留 `B[r][c]`，激活向东传递、部分和向南传递，每级寄存一拍。
- 计算核采用同步高有效复位，复位优先；复位期间对外 `valid` 为 0。
- Python 参考模型与 RTL 独立实现计算，逐拍检查同时验证数据及传递时序。

当前时序草案为装载 4 拍、注入 16 拍、捕获 16 拍；以任务接受为起点，第 24 拍产生最后一个结果、第 25 拍可握手，最小任务间隔为 26 拍。这些区间的重叠关系、周期编号和握手条件尚需在逐拍时序表中明确，再作为 RTL 的验收依据。

验收条件：

- 手算样例、单位阵、极值与固定种子随机向量逐元素一致。
- 逐拍 scoreboard 能检测数据流和时序错误，故障注入测试按预期失败。
- PE 与阵列分别综合，保留资源报告作为后续比较基线。

交付：数值与接口规格、逐拍时序表、Python 参考模型、测试向量、RTL、自检测试平台、检查脚本与综合报告。

## V2：单时钟 SoC

按以下顺序接入 CPU 与工作负载：

1. **Ibex 裸机基线**：固定 Ibex 版本和 simple-system 内存映射，运行裸机自检并输出唯一 PASS 标记；验证强制失败及未发出 halt 时的超时路径。
2. **NPU MMIO**：定义地址窗口、寄存器、原子提交、16 beat 结果读取、ACK、非法访问与复位语义。提交时快照 `task_id/A/B`；仅允许一个在途任务，忙时拒绝提交且不覆盖原任务，结果确认后才能接受下一任务。软件在读取结果前后执行 fence。
3. **真实网络层**：选择一个 16×16、融合 ReLU 的全整数 PTQ 全连接层。候选为 `hello_world_int8.tflite` 的 `dense_1`，模型来源、版本、张量形状和量化参数需先核实。软件分块提交并合并完整 K 维部分和，完成零点修正、一次 bias 累加与重新量化。

验收条件：裸机程序完成提交与结果读取，真实层结果与 Python 参考逐项一致；同时记录 Ibex 纯软件实现的周期数作为基线。

交付：依赖版本记录、裸机固件、MMIO RTL 与测试平台、模型提取记录、比对结果和周期统计。

## V3：双时钟 SoC

将 CPU 与 NPU 分为两个时钟域，命令与结果分别经过异步 FIFO。

设计约束：

- CPU 域写入完整任务快照后，才将命令提交至 FIFO。
- FIFO 指针使用格雷码与两级同步器跨域，数据存储体按读写协议访问。深度从 2、4 两档起步评估。
- 结果 FIFO 满时暂停输出；软件在非空时持续读取，不能等待 16 项全部入队后才开始读取。
- 跨域复位采用异步断言、各域同步释放。复位清空两个域的在途状态，由软件重新提交任务；计算核内部复位与域复位的衔接需在接口规格中明确。

验收条件：

- 覆盖至少两组频率比、非对齐相位、满空边界、背压和复位场景。
- 对 FIFO 做形式验证，检查已接受数据无丢失、重复或乱序，以及无读空、写满越界。
- 记录 CDC 结构与约束；仿真通过不能单独作为 CDC 签核依据。

交付：CDC 接口与复位规格、异步 FIFO、形式验证性质、系统测试及频率比实验记录。

## V4：FPGA 验证

在板上使用两路真实独立时钟，运行 V2 的网络层工作负载并保留可观测结果。

验收条件：

- 提供时钟定义、跨域时钟组及输入输出延迟约束，记录最差路径与时序余量。
- 记录纯软件基线周期、阵列计算周期、端到端周期、单任务延迟、连续任务吞吐、资源占用与最高可用频率，并说明测量条件。
- 比较至少两组频率比和两组 FIFO 深度，每次改变一个变量，保留未改善的结果及分析。
- 仅在有可信依据时报告功耗，并区分估计与实测。

交付：板卡配置、约束文件、运行步骤、时序与资源报告、性能对照结果。

## 范围边界

完整 MLP/CNN 推理、im2col 卷积映射、8×8 阵列、DMA/AXI、复杂低功耗与整 SoC GDS 均不纳入当前阶段。

真实网络层、纯软件基线、独立参考模型、自检测试与可复现脚本仍是计划中的验收内容。
